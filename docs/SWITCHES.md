# Depth switches

Generated by `python3 scripts/switches.py docs` from `config/switches.json` and `config/run_profiles.json`. Do not edit.

Every choice that trades depth for cost is a switch. Pick a preset, change any switch, and the run records what it did. A switch never caps a verdict or a confidence level: every report ends with a **Depth Disclosure** listing what was off, what that may cost in confidence, and the exact command that goes deeper.

```
python3 scripts/switches.py show --profile lean          # what a preset does
python3 scripts/switches.py explain reading                # one switch
python3 scripts/new_run.py ... --profile lean --set effort=xhigh
python3 scripts/switches.py disclosure RUN_DIR            # what a run left out
```

## What each switch does

### `reading`

- **Acts in:** Stage 0b. **Values:** on, off.
- **Buys:** Every in-scope page read once and recorded page by page.
- **Turning it down loses:** The page-by-page record of what was read; specialists read their own domain's documents instead.
- **May cost in confidence:** Accounting and governance findings rest on what specialists chose to open.
- **Can change:** until specialists.

### `digest`

- **Acts in:** Stage 0c. **Values:** on, off.
- **Buys:** Web summaries of each report, kept as tier-6 leads and page-confirmed by script.
- **Turning it down loses:** The leads that point specialists at what to read. Off only with reading on.
- **May cost in confidence:** None by itself: digest items are never evidence.
- **Can change:** until specialists.

### `second_reads`

- **Acts in:** Stage 0b. **Values:** on, off.
- **Buys:** An independent second read of every chunk, with conflicts adjudicated.
- **Turning it down loses:** The cross-check of a reader's misses. Only meaningful with reading on.
- **May cost in confidence:** A reading miss goes unnoticed.
- **Can change:** until specialists.

### `effort`

- **Acts in:** every Opus agent. **Values:** high, xhigh, max.
- **Buys:** More reasoning per turn.
- **Turning it down loses:** Reasoning depth per turn; not measured yet what that costs in findings.
- **May cost in confidence:** Unmeasured.
- **Can change:** until run start.

### `specialists`

- **Acts in:** Stage 1. **Values:** core, all.
- **Buys:** Every domain researched by its own independent head.
- **Turning it down loses:** core runs financials, filings, management, forecasting, valuation and bear-case: no industry, moat, scuttlebutt, concalls or special-situations reports, so thin evidence for some layers.
- **May cost in confidence:** Moat, industry and ground-truth judgments rest on indirect evidence.
- **Can change:** until specialists.

### `verifier_sample`

- **Acts in:** Stages 1-2. **Values:** small, full.
- **Buys:** More of each specialist's claims re-opened at the source (full 8, small 4).
- **Turning it down loses:** Fewer claims re-opened, so a misread is likelier to pass.
- **May cost in confidence:** Lower assurance that claims say what their sources say.
- **Can change:** at any time.

### `synthesis`

- **Acts in:** Stage 3. **Values:** compact, full.
- **Buys:** Independent theme analysts and section writers, five or six and seven sessions.
- **Turning it down loses:** compact uses two theme sessions and two writers. All four layer analysts still run, and every item still gets a recorded fate.
- **May cost in confidence:** Fewer independent eyes on how the evidence connects.
- **Can change:** until synthesis.

### `audit`

- **Acts in:** Stage 4. **Values:** sampled, full.
- **Buys:** The whole audit (full 30 claims and 15 restatements).
- **Turning it down loses:** sampled audits 15 claims and 8 restatements.
- **May cost in confidence:** Lower assurance on the final report.
- **Can change:** at any time.

### `history_years`

- **Acts in:** Stages 0-1. **Values:** 7, 10, 15.
- **Buys:** A longer record: more cycles, and more of management's history.
- **Turning it down loses:** Below 10 years the record may miss a full cycle.
- **May cost in confidence:** Through-cycle judgments rest on fewer cycles.
- **Can change:** until specialists.

### `gap_rounds`

- **Acts in:** Stage 2. **Values:** 1, until_closed.
- **Buys:** Every closable gap closed before synthesis.
- **Turning it down loses:** Closable gaps stay open after one round, and the report says which.
- **May cost in confidence:** Known gaps remain.
- **Can change:** at any time.

### `early_stop`

- **Acts in:** Stage 1. **Values:** on, off.
- **Buys:** A pause that asks the owner when a red flag appears early, before the rest is spent. Never an automatic kill.
- **Turning it down loses:** Off spends the full run on a name with a red flag, which a deep run may want anyway.
- **May cost in confidence:** None.
- **Can change:** at any time.

### `canaries`

- **Acts in:** verification and audit. **Values:** on, off.
- **Buys:** Known-false claims mixed into the checkers' samples: a measured catch rate for every run.
- **Turning it down loses:** The only measure of whether the checkers are working.
- **May cost in confidence:** None directly: it measures assurance rather than adding it.
- **Can change:** at any time.

### `spend_ceiling`

- **Acts in:** the engine. **Values:** number or none.
- **Buys:** An automatic pause when a run's recorded cost reaches this many dollars.
- **Turning it down loses:** With none, nothing pauses a run on cost.
- **May cost in confidence:** None.
- **Can change:** at any time.

### `reading_transport`

- **Acts in:** Stage 0b. **Values:** plan, batch.
- **Buys:** plan uses the subscription; batch reads through the API at half price, with real money and an API key.
- **Turning it down loses:** Nothing in depth: it changes who pays.
- **May cost in confidence:** None.
- **Can change:** until specialists.

## Combinations

- With `reading` off, `digest` on: with reading off the digest is Stage 0.
- With `reading` off, `second_reads` off: second reads apply only to the reading stage.
- With `reading` off, `reading_transport` plan: the batch transport applies only to the reading stage.
